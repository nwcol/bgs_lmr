## Contents

This document describes the loose files within this directory.
For information about its subdirectories, see the `README.txt` files in each
subdirectory.

[cytoBand.txt](cytoBand.txt): Chromosome band table. Downloaded from
https://hgdownload.cse.ucsc.edu/goldenPath/hg38/database/cytoBand.txt.gz.

[DFE\_overview.ods](DFE_overview.ods): A comparison of DFE parameters from
Kim et al. 2017 and Di et al. 2025 to those used in this study.

[DFE\_tbl.ods](DFE_tbl.ods): A table of DFE parameters used in this study.

[DFE\_tbl.csv](DFE_tbl.csv): A plaintext table of DFE parameters used in this
study.

[hg38.genome](hg38.genome): A table of chromosome lengths.

[site\_count\_tbl.csv](site_count_tbl.csv): A table of accessible site counts
for each mutation model/chromosome combination.
Created with [compute\_site\_counts.ipynb](../tools/compute_site_counts.ipynb)

[U\_tbl.csv](U_tbl.csv): A table of mutation rates for each class of
constrained elements, for each mutation/model chromosome combination.
Created with [compute\_U.ipynb](../tools/compute_U.ipynb).
