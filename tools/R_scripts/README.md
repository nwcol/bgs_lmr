## R Scripts

This directory holds R scripts that run correlation-based analyses of the human genomic landscapes. These include simple correlations as well as the Structural Equation Modeling pipeline which leans heavily on the lavaan package. 

In our original puplication, these are collectively referred to as "downstream analyses" because they run general-purpose statistical tools using the output of models based on population genetics theory.

The starting point of such analyses are the 10 kb tables that are generated by the python pipeline. The R scripts will look for the 10 kb tables using relative paths. Therefore, they are designed to be executed from within each subdirectory of the path `bgs_lmr/models/tables_10kb` (i.e., `equilibrium_granular_Ne` and `equilibrium_single_Ne`). The R scripts source from `HelperFunctions.R`, which loads the required packages and sets global variables and functions.
 They should be run in the following order: 

### Preparing tables 
`prepare_tables.R` loads 10 kb tables from different constraint elements and mutation maps, then uses them to simulate diversity and further transform them into tables of 100 kb and 1 Mb resolution. 
These are stored in a local directory called `maps`.

### Measurement models
`measurement_models.R` loads the tables generated by `prepare_tables.R`, then uses them to build measurement models of mutation rate variation and a synthetic construct of B-values from Principal Component Analyses.
These are also stored in `maps`.

### Fitting SEMs
`fit_obspi.R` loads the tables generated by `prepare_tables.R` and `measurement_models.R`, then uses them to fit path models of different structures (corresponding to DAGs 1-4 in our original publication) and at different scales (10kb -- 1 Mb).

This is where the heavy computation happens. 
The script defines, at the beginning of the section `Fitting models`, two boolean flags that specify whether the SEMs should be fit to resampled datasets. These are currently set to `FALSE`, in which case execution of `fit_obspi.R` should take about 1h. Otherwise, fitting SEMs to resampled datasets is an expensive task that increases execution time to around 48h.

`fit_simpi.R` is similar to `fit_obspi.R` except it fits SEMs using simulated genetic diversity (a variable generated by `prepare_tables.R`).

These scripts output text files to the subdirectory `sem`.

### Generating tables and figures
Both `plot_obspi.R` and `plot_simpi.R` take output from their respective fitting scripts to generate figures and summarizing tables that are output to the subdirectories `sem` and `plots`.

### Preparing tables
Finally, `plot_landscapes.R` loads previous tables as well as helper files to generate descriptive plots such as lanscapes highlighting candidate regions for associative overdominance.
