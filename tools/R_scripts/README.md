## R Scripts

This directory holds R scripts that run correlation-based analyses of the human genomic landscapes. These include simple correlations as well as the Structural Equation Modeling pipeline which leans heavily on the `lavaan` R package. 

In our original puplication, these are collectively referred to as "downstream analyses" because they run general-purpose statistical tools using the output of dedicated models specific to population genetics.

The starting point of such analyses are the 10 kb tables that are generated by the python pipeline. The R scripts will look for the 10 kb tables using relative paths. Therefore, they are designed to be executed from within each subdirectory of the path `bgs_lmr/models/tables_10kb` (i.e., `equilibrium_granular_Ne` and `equilibrium_single_Ne`). Each individual script sources from `HelperFunctions.R`, which loads the required packages and sets global variables and functions.
 They should be executed in the following order: 

### Preparing tables 
`prepare_tables.R` loads 10 kb tables from different constrained elements (CDS + phastCons or CDS + regulatory models) and mutation maps, then uses them to simulate diversity and further generate tables of 100 kb and 1 Mb resolution. 
These are stored in a local directory called `maps`.

### Measurement models
`measurement_models.R` loads the tables generated by `prepare_tables.R`, then uses them to build measurement models of mutation rate variation and a synthetic construct of B-values from Principal Component Analyses.
These are also stored in `maps`.

### Fitting SEMs
`fit_obspi.R` loads the tables generated by `prepare_tables.R` and `measurement_models.R`, then uses them to fit path models (DAGs 1-4 in our original publication) at different scales (10kb -- 1 Mb).

This is where the heavy computation happens. 

The script defines, at the beginning of its header `Fitting models`, two boolean flags (`boot` and `permut`) that specify whether the SEMs should be fit to resampled datasets. These are currently set to `FALSE`, in which case execution of `fit_obspi.R` should take about 1h. Otherwise, fitting SEMs to resampled datasets is quite expensive and increases runtime to around 48h.

`fit_simpi.R` is similar to `fit_obspi.R` except it fits SEMs using simulated genetic diversity (a variable generated by `prepare_tables.R`).

`fit_simpi.R` and `fit_obspi.R` output text files to the subdirectory `sem`.

### Generating tables and figures
Both `plot_obspi.R` and `plot_simpi.R` take output from their respective fitting scripts to generate figures and tables that are output to the subdirectories `sem` and `plots`.

### Other plots
Finally, `plot_landscapes.R` loads previous tables as well as helper files to generate other descriptive (perhaps less technical) plots such as lanscapes that highlight candidate regions for associative overdominance.
