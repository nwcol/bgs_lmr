## R Scripts

This directory holds `R` scripts that run statistical analyses of the human genomic landscapes. These include simple correlations as well as the Structural Equation Modeling (SEM) pipeline which leans heavily on the `lavaan` package in `R`. 

In our original publication, these are collectively referred to as "downstream analyses" because they adopt general-purpose statistical tools using the output of population-genetic models.

The starting point of such analyses are the 10 kb tables that are produced by the `python` pipeline. The `R` scripts look for the 10 kb tables using relative paths. Therefore, they are designed to be executed from within each subdirectory of the path `bgs_lmr/models/tables_10kb` (e.g., `equilibrium_granular_Ne`). Each individual script sources from `HelperFunctions.R`, which loads the required packages and sets global variables and functions.
Scripts also presume the existence of directories names `maps`, `sem` and `plots` within each model in `bgs_lmr/models/tables_10kb`. These should be created manually.

Scripts should be executed in the following order: 

### Preparing tables 
`prepare_tables.R` loads 10 kb tables from different constrained elements (CDS+phastCons or CDS+regulatory models) and mutation maps. This script also simulates diversity (from `E[pi]`) and generates tables of 100 kb and 1 Mb resolution. 
These are stored in the `maps` directory.

### Measurement models
`measurement_models.R` loads the tables generated by `prepare_tables.R`, and uses them to build measurement models of mutation rate variation and a synthetic construct of B-values from Principal Component Analyses.
These are also stored in the `maps` directory.

### Fitting SEMs
`fit_obspi.R` loads the tables generated by `prepare_tables.R` and `measurement_models.R`, then uses them to fit path models (DAGs 1-4 in our original publication) at different scales (10kb, 100 kb, 1 Mb).

This is where the heavy computation happens. Execution can take a couple of hours.

The script defines, at the beginning of its header `Fitting models`, two boolean flags (`boot` and `permut`) that specify whether the SEMs should be fit to resampled datasets. These are currently set to `FALSE`, in which case execution of `fit_obspi.R` should take about 1h. Otherwise, fitting SEMs to resampled datasets is quite expensive and increases runtime to around 48h.

`fit_simpi.R` is similar to `fit_obspi.R` except it fits SEMs using simulated genetic diversity (a variable generated by `prepare_tables.R` that is described in Supplemental section 5.1 of the original publication).

`fit_simpi.R` and `fit_obspi.R` output text files to the subdirectory `sem`.

### Generating tables and figures
Both `plot_obspi.R` and `plot_simpi.R` take output from their respective fitting scripts to generate figures and tables that are output to the subdirectories `sem` and `plots`.

Finally, `plot_landscapes.R` loads previous tables as well as helper files to generate other descriptive (less technical) plots such as lanscapes that highlight candidate regions for associative overdominance.

### Other scripts

The `Other` directory contains scripts not part of the main pipeline.
Notably, `mu_exons_pipeline.Rmd` specifies the pipeline for fitting DFEs in genes split by deciles of constraint.

### Alternative models

The `Alt_models` directory contains scripts for fitting and plotting SEMs under (1) the Cousins et al demography, (2) different cut-offs for the inclusion of phastCons, (3) the deCODE recombination map and (4) data from individual-based forward simulations. 
Loosely speaking, these are modified versions of the main  `R` pipeline. Each script is adjusted to handle the idiosyncrasies of its corresponding alternative scenario.
Running these scripts will require adjusting the path of the loaded files.
